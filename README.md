# GENAI - Assignment 3 : Functions

## 📌 Overview

 The assignment covers basic functions, recursion, lambda functions, `map()`, `filter()`, default arguments, and combining multiple concepts to solve real-world problems.

---

## 🎯 Objectives

- Understand how Python functions work.
- Practice using parameters and return values.
- Learn recursive functions.
- Use lambda functions for short operations.
- Apply `map()` and `filter()` effectively.
- Build simple utility functions using loops and function calls.

---

## 📝 Tasks Included

### ✅ Task 1 – Price After Discount
- Created a function to calculate the final price after applying a discount.
- Used a default discount of **5%** when no discount is provided.
- Tested the function with different values.

---

### ✅ Task 2 – Recursive Factorial
- Implemented a recursive function to calculate the factorial of a number.
- Handled:
  - Base case (`0` and `1`)
  - Negative number validation

---

### ✅ Task 3 – GST Calculator
- Created a lambda function to calculate the final price after adding **18% GST**.
- Tested the lambda with sample values.

---

### ✅ Task 4 – Apply GST Using `map()`
- Applied the GST lambda function to a list of prices using `map()`.
- Displayed:
  - Original price list
  - Updated price list after GST

---

### ✅ Task 5 – Filter Expensive Products
- Used `filter()` to separate:
  - Products priced above **₹500**
  - Products priced **₹500 or below**

---

### ✅ Task 6 – Combined Utility Function
Created a function that:
- Applies a **10% discount** using `map()`
- Filters prices greater than **₹300**
- Returns both:
  - Discounted price list
  - Filtered price list

---

### ✅ Task 7 – Menu Using Functions
Implemented three functions:
- Add a price
- Calculate average price
- Find maximum price

Created a menu-driven program using loops and function calls.
